The trust gap

A single agent grading its own work is not verification.

Most agent systems collapse implementation, review, and completion authority into one model. The result may sound certain without being independently checked.

Rally gives models incompatible authority. An agent can own work or approve it—never both. The runner rejects any attempt to blur that line.

Questions executives ask

Clear answers before access.

Are two agents just agreeing with each other?

No. They come from different model families, and the runner—not either agent—enforces ownership, evidence, rejection, and verification transitions.

Do emails literally trigger the next model turn?

The first email starts the real run and every turn is mirrored to the thread. The authoritative runner dispatches the next model locally; it does not wait for email re-delivery.

What happens when the agents cannot finish?

Rally stops. A blocked item, repeated disagreement, no progress, timeout, or budget limit produces an explicit halt report instead of an endless loop.

Does Rally store prompts in Cloud logs?

No. Cloud Trace and structured logs capture metadata such as run ID, status, and latency. Prompt and response content capture is disabled.
